# SoccerMatchVisualization

A Unity project that brings a soccer match to life — visualizing real match data as a fully animated 3D replay, complete with players, referee, and ball.

---

## About

This project was built as a technical assignment for a Unity Developer role. The goal was to take a structured JSON dataset of a real soccer match and visualize it inside Unity, turning raw numbers into a watchable replay on a 3D pitch.

The focus was on getting everything right: players from both teams clearly moving across the pitch, the referee visible and trackable, and the ball behaving correctly throughout the match.

Once the core experience was solid, a **rewind feature** was added — so you can instantly jump back to any moment in the match and relive your favorite plays.

---

## Features

- **Players & Referee** — All entities move accurately based on the match data
- **Ball Tracking** — The ball is always visible and follows the real match events
- **Rewind** — Jump back to any moment in the match with a single button

---

## Getting Started

1. Clone the repository
2. Open the project folder in **Unity Hub**
